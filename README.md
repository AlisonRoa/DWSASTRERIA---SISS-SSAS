# Data Warehouse ETL Pipeline

Pipeline ETL para la extracción, transformación y carga de datos hacia un Data Warehouse utilizando SQL Server.

## 🚀 Descripción

Este proyecto implementa un proceso ETL que permite integrar datos desde diferentes fuentes, transformarlos según reglas de negocio y cargarlos en un modelo analítico optimizado para consulta.

## 🔄 Flujo ETL

1. **Extract**
   Extracción de datos desde fuentes (archivos, bases de datos, etc.)

2. **Transform**
   Limpieza, normalización y aplicación de reglas de negocio

3. **Load**
   Carga de datos en tablas del Data Warehouse

## 🧱 Tecnologías

* SQL Server
* SSIS (SQL Server Integration Services)
* T-SQL

## 📁 Estructura del proyecto

* `ETL/` → paquetes de integración
* `Scripts/` → consultas SQL
* `DataWarehouse/` → modelo de datos

## 🧠 Enfoque técnico

El pipeline está diseñado para garantizar:

* Integridad de datos
* Transformaciones consistentes
* Carga eficiente en el Data Warehouse

## ⚙️ Ejecución

1. Configurar conexión a SQL Server
2. Ejecutar paquetes SSIS
3. Validar carga en el Data Warehouse
